# **우테코 8기 프리코스 3주차 과제: 로또**

## **✨ 기능 목록**

### **📥 입력 기능**

1. **로또 구입 금액**
    - 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
        
        ```jsx
        14000
        ```
        
    - **예외 처리**
        - 입력값이 없을 경우
        - 구입 금액이 숫자가 아닌 경우
        - 구입 금액이 음수인 경우
        - 구입 금액이 1000원으로 나누어 떨어지지 않는 경우
2. **당첨 번호**
    - 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.
        
        ```jsx
        1,2,3,4,5,6
        ```
        
    - **예외 처리**
        - 입력값이 없을 경우
        - 입력값에 숫자가 아닌 값이 포함 된 경우
        - 0 이하의 수를 입력한 경우
        - 46 이상의 수를 입력한 경우
        - 값의 개수가 5개 이하인 경우
        - 값의 개수가 7개 이상인 경우
3. **보너스 번호**
    - 보너스 번호를 입력 받는다.
    
    ```jsx
    7
    ```
    
    - **예외 처리**
        - 입력값이 없을 경우
        - 입력값에 숫자가 아닌 값이 포함 된 경우
        - 0 이하의 수를 입력한 경우
        - 46 이상의 수를 입력한 경우

### **📤 출력 기능**

1. **발행한 로또의 수량 및 번호**
    - 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.
    
    ```jsx
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    [7, 11, 16, 35, 36, 44]
    [1, 8, 11, 31, 41, 42]
    [13, 14, 16, 38, 42, 45]
    [7, 11, 30, 40, 42, 43]
    [2, 13, 22, 32, 38, 45]
    [1, 3, 5, 14, 22, 45]
    ```
    
2. **당첨 내역**
    - 당첨 내역을 출력한다.
    
    ```jsx
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```
    
3. **수익률**
    - 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
    
    ```jsx
    총 수익률은 62.5%입니다.
    ```
    
4. **에러**
    - 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
    
    ```jsx
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    ```
    

## **🛠️ 컴포넌트별 역할**

- ***InputView / OutputView***
    - 콘솔 입출력을 전담하는 컴포넌트.
    - 로직을 가지지 않고, 사전에 정의된 메시지를 출력하거나 사용자 입력을 받는 역할만 수행한다.
- ***constants / messages***
    - 애플리케이션 전반에서 사용되는 상수와 메시지를 관리한다.
    - 오류 메시지, UI 문구, 이름 길이 제한 등을 포함한다.
- ***Lotto***
    - 로또 객체의 생성을 담당한다.
    - 형식에 맞는 로또인지 검증한다.
- ***LottoCashier***
    - 유저가 몇개의 로또를 구매 희망하는지 파싱하고, 구매가 가능한 금액인지 검증한다.
- ***LottoWinChecker***
    - 유저로부터 받은 당첨 번호와 구매한 번호를 대조해 당첨된 로또의 종류와 개수를 반환한다.
- ***LottoController***
    - 사용자 입력부터 최종 결과 출력까지, 전체 애플리케이션의 흐름을 제어하는 지휘자 역할.
    - 각 컴포넌트(Model, View, Parser)에 필요한 작업을 요청하고 데이터를 전달한다.

## **🚗 실행 플로우**

1. **프로그램 시작**
    - npm start 명령어로 App.js를 실행하면, RaceController의 run 메서드가 호출되며 전체 프로세스가 시작된다.
2. **구매 금액 입력**
    - **Controller → View**: InputView.getMoney를 호출해 사용자 입력을 요청한다.
    - **사용자 입력 예시**: 4000
3. **입력값 파싱**
    - **Controller → Parser**: 입력받은 문자열을 LottoCashier에 전달한다.
    - **파싱 결과**: 4
4. **Car 객체 생성**
    - **Controller → Model**: 파싱해 받은 숫자만큼 로또를 생성한다.
    - **생성 결과**:
        
        [8, 21, 23, 41, 42, 43]
        [3, 5, 11, 16, 32, 38]
        [7, 11, 16, 35, 36, 44]
        [1, 8, 11, 31, 41, 42]
        
5. **당첨 번호 입력**
    - **Controller → View**: InputView.getWinningNumbers()를 호출해 사용자 입력을 요청한다.
    - **사용자 입력 예시**: 1,2,3,4,5,6
6. **보너스 번호 입력**
    - **Controller → View**: InputView.getBonusNumber()를 호출해 사용자 입력을 요청한다.
    - **사용자 입력 예시**: 7
7. **당첨 로또 확인**
    - **Controller → View**: OutputView.printResultHeader()를 호출해 "당첨 통계\n—-" 헤더를 출력한다.
    - **Controller → Model**: LottoWinChecker.findWinningLottos()를 호출해 당첨된 로또들을 반환한다..
    - **Model: Race**: 시도 횟수만큼 각 Car의 race() 메서드를 호출하며 라운드별 결과를 내부에 기록한다.
8. **일치 로또 표기 /수익률 계산**
    - **Controller → Model**: 일치 로또를 찾고, 수익률을 계산한다.
9. **최종 우승자 발표**
    - **Controller → View**: 반환받은 당첨 로또들과 수익률을 출력한다.

## **📚 고려했던 포인트**

### **1. 각 메소드의 기능 최소화**

각 메소드가 어떤 로직을 담당하고 무엇을 반환하는지, 길이가 15줄이 넘어가는지 이 두가지를 유의하면서 구현했다. 하나의 로직 덩어리이자 코드블록으로 묶을 수 있어 보이는 로직들을 클래스 내의 프라이빗 메소드나 함수로 분리해 각 메소드의 책임을 최소화했다.

### **2. 값을 하드 코딩하지 않기 / 비즈니스 로직 변경 고려**

상수화 할 수 있는 값들은 상수화 하는 방식으로, 하드코딩을 피하려고 노력했다. 이는 상수들을 한 군데에서 관리할 수 있어 유지보수성에서 장점응 제공하고, 언제든지 변할 수 있는 비즈니스 로직에 유연하게 대처할 수 있게 한다. 로또의 등수를 정하는 일치 개수의 조건과 상금의 액수는 언제든지 바뀔 수 있다.

### **3. 최소 단위의 테스트부터 구현하는 tdd의 필요성 / 테스트를 작성하는 이유**

최소 단위의 테스트가 구현되지 않은 상태에서 구현을 먼저 한다면, 매번 npm start 명령어를 통해 콘솔에서의 e2e를 수동으로 매번 해야 한다는 단점이 있고, 디버깅에서도 불리한 점이 분명히 존재한다.
